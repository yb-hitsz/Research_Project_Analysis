第一份讨论选哪个环节；第二份讨论如何从执行经验中持续改进；第三份讨论图表示与预训练能迁移什么；第四份从更广的数据挖掘进展出发，区分热门方向与适合 EDA 的可执行研究问题；第五份介绍三维集成领域，区分开放工具的能力与边界；第六份讨论是否需要替代传统 GNN，以及电路表示应保留的信息、计算方式和值得验证的新方向；第七份聚焦先进工艺和新器件带来的标准单元库问题及开放研究条件；第八份分析不依赖训练模型的 EDA 研究空间，给出近期证据和适合现有标准单元工作基础的选题方案；第九份回答缺少工艺背景与企业资源时，如何取得可信资料、识别关键缺口并开展可验证的新工艺研究。

前九份报告主要包含一手资料链接、研究方案和已有实验分析；第十份还记录本轮新完成的受限算法对照实验，明确区分开发摸底、既有结果与尚未执行的方案，不预设新颖性或正面结果。文中原项目的内部记录路径用于说明证据来源；本仓库不附带这些原始记录、第三方源码、PDK、商业工具或数据集。
